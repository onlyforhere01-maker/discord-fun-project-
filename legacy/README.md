# Legacy TanStack Start app

This folder holds the previous **2D scroll playground** (TanStack Start + React + Cloudflare Workers SSR). It is **not** the main site anymore.

The live experience is the folio-2025 fork at the repo root (`npm run dev` / `npm run build`).

To run the old UI locally (optional):

```bash
cd legacy
# copy package.json from git history or reinstall TanStack deps if you restore a standalone package.json
```

Content for the 3D world is sourced from [`../content/playground.json`](../content/playground.json).
